Handoff notes · T1 and T2
Layout Card padding:10px 8px 8px — the finalized widget from the full-page design: header is the "Current point" eyebrow with the 28px point stepper right-aligned, no rule under it; header row of 10px ink-400 labels over a hairline; 40px rows at 8px radius; a hairline footer carrying shot count, how the point ended, and "Edit this point". Column gap 20px throughout. Placement takes the one fluid track in both states; Mph is tabular and right-aligned. Rule Rail open: # · Player · Stroke · Placement · Result. Rail collapsed (⌘\, 168px returned): Spin · Type · Mph join, in the order a player says the shot. The five shared columns hold the same x in both states — columns are added and removed, never re-sorted. This supersedes 2g's own eight-column set at 828px. Behavior Stepper walks points under the applied cut and keeps the list, the player and the strip in sync — one selected-point store, not three. Row click seeks the film to that shot; the serve row reads "Serve", later rows the bare stroke. Fullscreen is entered from the player’s own maximize control, not from this header — the widget carries no "Open fullscreen" link. No prose sentence above the table — the last row's Result and the footer already say how the point ended. Data Shots from the point's own record — nothing here is reachable only through the wide feed. Unmeasured speed is an ink-400 em dash, never 0; same for spin and placement. Score pill = the score at the start of the point. Accept Toggling the rail adds columns without moving the five · a two-shot point (ace, double fault) draws the same head and one or two rows, never an empty state · the rail toggle's label and tooltip say nothing about columns.
