  - [ ] A new pure module `leave-guard.ts` exports `shouldAskBeforeLeaving({ armed, currentPath, href, event })`. It returns false when not armed, when the href's pathname equals `currentPath` (the navigation does not leave the screen), and for a modified or non-primary click (meta, ctrl, shift, alt, or `button !== 0`), since those open a new tab. It returns true otherwise. The module also exports `leaveConfirmLabel(label?)`, which gives `"Go to <label>"` for a non-blank label and `"Leave this page"` for a missing or blank one.
